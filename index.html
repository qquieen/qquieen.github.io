1. yt-dlp

最推荐 Recommended 活跃维护 Active 功能强大 Feature-rich

简介 | Description

中文： yt-dlp 是 youtube-dl 的一个功能增强版分支，支持更多网站、更快的下载速度和更多新特性。它是目前最活跃和功能最强大的YouTube视频下载工具。

English: yt-dlp is a feature-rich fork of youtube-dl with additional features, better performance, and support for more sites. It's currently the most actively maintained and powerful YouTube downloader.

主要特性 | Key Features

  • 支持1000+视频网站（包括YouTube、Bilibili等） | Supports 1000+ video sites
  • 下载速度更快，支持并行下载 | Faster downloads with parallel fragment downloading
  • 支持SponsorBlock自动跳过赞助内容 | SponsorBlock integration
  • 定期更新以应对YouTube的限制 | Regular updates to counter YouTube restrictions
  • 支持字幕下载和嵌入 | Subtitle download and embedding
  • 支持播放列表和频道下载 | Playlist and channel download support

安装方法 | Installation

# 使用 pip 安装 | Install using pip
pip install yt-dlp

# 或使用 brew (macOS) | Or using brew (macOS)
brew install yt-dlp

基本使用 | Basic Usage

# 下载视频（最佳质量） | Download video (best quality)
yt-dlp "VIDEO_URL"

# 下载指定格式 | Download specific format
yt-dlp -f "bestvideo[ext=mp4]+bestaudio[ext=m4a]" "VIDEO_URL"

# 下载播放列表 | Download playlist
yt-dlp "PLAYLIST_URL"

3. Tartube

图形界面 GUI 易用 User-friendly

简介 | Description

中文： Tartube 是一个带有图形界面的YouTube下载器，基于 youtube-dl 和 yt-dlp。适合不习惯命令行的用户。

English: Tartube is a GUI front-end for youtube-dl and yt-dlp. Perfect for users who prefer graphical interfaces over command-line tools.

主要特性 | Key Features

  • 友好的图形用户界面 | User-friendly graphical interface
  • 支持频道和播放列表管理 | Channel and playlist management
  • 自动下载新视频 | Automatic download of new videos
  • 跨平台支持 (Windows, Linux, macOS) | Cross-platform support

4. PyTube

Python库 Library 易集成 Easy Integration

简介 | Description

中文： PyTube 是一个轻量级的Python库，无需外部依赖即可下载YouTube视频。适合开发者集成到自己的项目中。

English: PyTube is a lightweight Python library for downloading YouTube videos without external dependencies. Ideal for developers to integrate into their projects.

主要特性 | Key Features

  • 纯Python实现，无外部依赖 | Pure Python with no dependencies
  • 简单易用的API | Simple and easy-to-use API
  • 支持字幕下载 | Caption/subtitle download support
  • 适合程序集成 | Great for programmatic use

基本使用 | Basic Usage

from pytube import YouTube

# 下载视频 | Download video
yt = YouTube('VIDEO_URL')
stream = yt.streams.get_highest_resolution()
stream.download()
